# DevMetrics - Code Quality Analysis Toolkit

Automated code quality analysis for modern development workflows.

## Features
- Code complexity analysis (McCabe, Halstead)
- Dependency security scanning
- Performance hotspot detection
- Multi-language support: Python, JS/TS, Go, Java

## Quick Start
1. Clone this repository
2. Open in WorkBuddy
3. The toolkit will automatically initialize on first open
